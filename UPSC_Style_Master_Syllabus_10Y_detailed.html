Paper 1 — Core Mathematics, Statistics & ML Foundations (mandatory)

Section 1.1: Probability & Distributions (L1→L3)

  • Topics:
    • Probability basics: sample space, events, probability axioms
    • Conditional probability & Bayes' theorem — priors, likelihoods, posteriors
    • Discrete distributions: Bernoulli, Binomial, Poisson, Multinomial
    • Continuous distributions: Uniform, Normal, Exponential, Gamma, Beta
    • Central Limit Theorem (CLT) and law of large numbers
    • Joint, marginal, conditional distributions and independence
  • Study notes / Formulas:
    • P(A|B) = P(A∩B)/P(B); Bayes rule and conjugate priors (Beta-Bernoulli)
    • Expectation, variance, covariance, moment-generating functions
  • Example tasks:
    • Derive posterior for Beta-Bernoulli conjugacy; compute credible interval
    • Use CLT to approximate sampling distribution and compute confidence intervals
  • Must be able to:
    • Solve conditional probability puzzles, compute expected values and variances for compound distributions, and explain when CLT applies.

Section 1.2: Statistical Inference & Hypothesis Testing (L1→L3)

  • Topics:
    • Point estimation (MLE), method of moments; properties of estimators (bias, variance, consistency, efficiency)
    • Confidence intervals and interpretation; bootstrap CI
    • Hypothesis tests: null, alternative, Type I/II errors, p-values, likelihood ratio tests
    • t-tests, z-tests, chi-square tests, ANOVA basics; nonparametric tests (Mann-Whitney, KS)
    • Power analysis and sample size calculation; multiple testing corrections (Bonferroni, BH-FDR)
  • Example tasks:
    • Design an A/B experiment with sample size calculation for a minimum detectable effect
    • Interpret test results with assumptions, compute power and type-II error
  • Must be able to:
    • Choose appropriate statistical tests, compute power, and justify conclusions with assumptions and limitations.

Section 1.3: Linear Algebra & Optimization (L1→L3)

  • Topics:
    • Vectors and matrices: multiplication, transpose, norms, condition number
    • Linear independence, rank, nullspace, orthogonality
    • Eigenvalues, eigenvectors, spectral decomposition
    • Singular Value Decomposition (SVD) and PCA derivation and hands-on
    • Convex sets/functions, gradients, Hessian, convex optimization basics
    • Optimization algorithms: gradient descent, momentum, SGD, Adam, LBFGS
    • Regularization: L1/L2, Elastic Net; effect on bias/variance
  • Example tasks:
    • Derive PCA via eigen-decomposition; implement SVD-based low-rank recon
    • Derive closed-form ridge solution and show effect of lambda on coefficients
  • Must be able to:
    • Manipulate matrices for model derivations and explain optimizer dynamics; select optimizer for a task.

Section 1.4: Core ML Algorithms & Theory (L1→L3)

  • Topics (for each algorithm list: objective, key hyperparams, complexity, failure modes):
    • Linear & Logistic Regression (loss, link, regularization)
    • Decision trees: splitting (Gini, Entropy), pruning, CART vs C4.5
    • Ensemble methods: Bagging, Random Forests, Gradient Boosting (XGBoost/LightGBM/CatBoost internals)
    • SVM: hinge loss, kernels, margin, slack variables
    • k-NN, Naive Bayes, K-Means clustering, Gaussian Mixture Models
    • Neural networks: perceptron, MLP, activations, backpropagation basics
  • Example tasks:
    • Implement logistic regression using gradient descent and verify convergence
    • Train a tree; plot learning curves and show overfitting/underfitting diagnostics
  • Must be able to:
    • Explain algorithmic trade-offs and choose the right model for a given business constraint.

Section 1.5: Model Evaluation & Generalization (L1→L3)

  • Topics:
    • Classification metrics: accuracy, precision, recall, F1, confusion matrix
    • Calibration, ROC, AUC, Brier score; precision-recall curves for imbalanced tasks
    • Ranking metrics: precision@k, NDCG, MAP
    • Regression metrics: MAE, MSE, RMSE, R^2
    • Cross-validation: k-fold, stratified, time-series split, nested CV; leakage detection
  • Example tasks:
    • Build calibration plots and compute Brier score; perform nested CV for honest hyperparameter tuning
  • Must be able to:
    • Choose suitable metrics tied to business objectives and detect leakage.

Section 1.6: Practical Tools & Libraries for ML Foundations (L1→L2)

  • Topics:
    • numpy, scipy (linear algebra, optimization), pandas (groupby/pivot/joins/reshaping)
    • scikit-learn APIs for pipelines, preprocessing, and model evaluation
    • matplotlib/seaborn/plotly for EDA and reporting
    • statsmodels for inference and time-series basics
  • Example tasks:
    • Complete 10 EDA notebooks using pandas and visualization; convert 3 notebooks into reproducible scripts
  • Must be able to:
    • Use pandas idioms for aggregation/sessionization and produce concise insights and charts.
